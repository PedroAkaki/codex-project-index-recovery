# Naming decision

Chosen public name: **Codex Project Index Recovery**. Skill and repository identifier: `codex-project-index-recovery`.

| Candidate | Benefit | Limitation |
| --- | --- | --- |
| Project Index Recovery | Precise about the index | Does not identify Codex; may suggest a general search-index tool |
| Codex Project Recovery | Familiar symptom and product | Can suggest deleted-file recovery; a public similarly named Recovery Manager project exists |
| Codex Sidebar Recovery | Easy to understand | Understates the project catalog and chat-association scope |
| Codex Project Index Recovery | Product, object and action are explicit | Longer; explain “index” in the human-facing subtitle |

This is an editorial decision based on scope, discovery and a focused public web search, not a trademark clearance or measured popularity study. Agent selection depends strongly on the frontmatter description, not a catchy name alone. The display name is 28 characters, within the published 30-character plugin listing limit.

The earlier locally installed `codex-project-recovery` identifier remains unchanged for compatibility during this beta. Install one version rather than both to avoid duplicate discovery.
